# Interface text

Use sentence case for interface labels: capitalise the first word, then ordinary words in lowercase. Apply this to buttons, navigation, headings, field labels, placeholders and accessibility labels.

Examples: **Import Aurora character**, **New character**, **Add folder**, **Sign in**, **Saving throws**, **Base value**.

Preserve proper names and acronyms, including DiceCloud, Aurora, Patreon, Google, Discord, GitHub, D&D, SRD, HP, AC, DC and URL. Keep names supplied by players, DMs and reference content as authored.

Write the intended capitalisation in the label itself. Do not use CSS to transform all interface text, since that can alter names and acronyms. When changing a visible label, keep its accessibility name and browser selectors aligned.
