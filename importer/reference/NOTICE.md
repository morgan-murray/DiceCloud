# Aurora Core Reference (2014), version 1.0.0

This built-in pack is included with the application and requires no upload. Its numeric definitions and short descriptions were newly authored for the importer. Aurora identifiers are retained for interoperability. The pack is an adapted, partial mechanical reference based on SRD 5.1, licensed CC-BY-4.0. It is not the complete SRD or a Player's Handbook library. It contains six ability increases, six saving-throw proficiencies, eighteen skill proficiencies, nine alignment labels, six size labels, four sense labels/ranges, thirty-nine manual damage-condition labels and three build-option labels.

This work includes material taken from the System Reference Document 5.1 (“SRD 5.1”) by Wizards of the Coast LLC and available at https://dnd.wizards.com/resources/systems-reference-document. Changes: translated a small subset of mechanics into Aurora-compatible identifiers and XML numeric definitions; all descriptions are shortened new summaries. These definitions target the 2014 rules. They do not implement 2024 rules or automatic level-up. No affiliation or endorsement is implied.

Flare's complete internal_elements.xml is not bundled: it mixes internal definitions and copied rulebook prose, with no separate grant established for every embedded text. No PHB descriptions, Flare UI assets, commercial compendium, spell/class/race catalogue, or automatic content downloads are included. Unknown required definitions remain explicit import errors rather than empty placeholder rules. Additional content must be supplied as private packs.

Built-in definitions are immutable. An identical duplicate from a user pack is deduplicated only if its complete canonical element matches; a differing duplicate is rejected with BUILTIN_ELEMENT_CONFLICT. Uploaded filenames cannot masquerade as built-in files. There is no implicit last-file-wins policy. Built-in pack ID/version/hash and private-file hashes form the content fingerprint saved in previews and imported sheets. Updating the pack changes future fingerprints, never previously saved snapshot totals.
