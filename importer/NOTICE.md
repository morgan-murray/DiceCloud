# Source and licensing

The headless `aurora.query.Query`, `aurora.content.CompendiumQuery` and `aurora.logic.LogicSolver` adapt the stat aggregation, element lookup and requirement concepts from Egorobi/Flare, pinned at `3905811e545b07875051d9f46f0ee1b93b5fd13b` (https://github.com/Egorobi/Flare). Those files retain MPL-2.0 coverage; the complete licence is in LICENSE-MPL-2.0. Source is distributed with this fork. The implementation replaces desktop paths, globals, unbounded expression loops, debug output and unsafe XML loading with per-request bounded interfaces and explicit errors.

No Flare UI/native launcher, saved character, asset or complete rulebook corpus is included. Flare's `data/elements/internal_elements.xml` is replaced by a built-in, versioned Aurora Core Reference (2014) pack containing newly authored definitions and short SRD-based summaries. See reference/NOTICE.md for its scope, CC-BY-4.0 attribution and exclusions. The full mixed-source original file is not redistributed. Basic numeric defaults and fixture rules are independently authored. The fixtures and their expected results are newly invented CC0 examples, not extracts from commercial characters or books.
